# Smart Hotkeys example

Interactive desktop tester with recording, manual F13–F24 selection, modifier
chips, multiple registrations, pause/resume and press/release logging.

See [testing instructions](../docs/TESTING.ru.md) and [API](../docs/API.ru.md).
Run `flutter run -d windows` from this directory, or use the direct dart.exe /
flutter_tools.snapshot commands in the testing instructions on Windows.
The app tests callbacks; it does not access a microphone or persist bindings.
